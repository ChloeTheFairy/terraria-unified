# terraria-unified

> standalone 1.4.5.x terraria mod

---

**terraria-unified** is a simple project built on top of the same infrastructure as tModLoader, porting the game to **.NET 10**, **SDL 3**, and **FNA 26.01**.

This project is **not a mod loader**, but it features its own improvements and tweaks to gameplay and performance. For now, you can read more about it [here](https://forums.terraria.org/index.php?threads/1-4-5-x-terraria-unified-standalone-1-4-5-mod-qol-features-and-better-performance.130432/).
